# Procedures, Views e Functions SQL Server

Este repositório reúne Procedures, Views e Functions desenvolvidas em SQL Server utilizando T-SQL durante meus estudos em Análise e Desenvolvimento de Sistemas.

## Conteúdo

* Procedures para consultas, relatórios e manipulação de dados.
* Views para simplificar consultas e organização das informações.
* Functions para cálculos e reutilização de lógica no banco de dados.
* Exemplos utilizando `CASE`, `CURSOR`, `WHILE`, `JOINs` e outras estruturas do T-SQL.

## Tecnologias

* SQL Server
* T-SQL
* SQL Server Management Studio (SSMS)

Este repositório faz parte do meu portfólio de estudos e prática em Banco de Dados.
